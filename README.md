# 교사용 AI 비서

교사의 시간표, 학사일정, 수업 진도, 일정과 업무를 한곳에서 관리하고 AI 비서를 통해 필요한 정보를 확인하거나 기록할 수 있도록 만든 웹 기반 온라인 교무수첩입니다.

## 실행 방법

이 프로젝트는 웹 기반 서비스입니다.

배포 URL:
https://solssamaiassistant.vercel.app

심사 시에는 배포 URL에 접속한 뒤 "미리보기 모드"를 이용하면 별도의 개인 정보나 실제 학교 데이터를 입력하지 않고 주요 기능을 확인할 수 있습니다. 로그인 화면의 "미리보기로 체험하기" 버튼으로 시작합니다.

dist 폴더에는 제출 시점의 빌드 결과물이 포함되어 있습니다.

## 주요 기능

- **오늘의 브리핑**: 오늘 수업, 일정, 마감 업무를 홈 화면에 모아 보여주고, 수업마다 반별 진도 기준으로 오늘 할 내용을 안내합니다.
- **AI 비서**: 대화로 시간표, 진도, 일정, 업무를 조회하거나 기록할 수 있습니다. 예를 들어 "3학년 2반 지방까지 했어"처럼 말하면 진도에 반영됩니다.
- **기본 시간표 및 일시 변경**: 주간 기본 시간표를 관리하고, 특정 날짜의 수업만 일시적으로 바꿀 수 있습니다.
- **월별 수업 진도 및 반별 진도 관리**: 월별 진도 계획과 항목별 차시를 입력하고, 반마다 완료·진행 중 상태와 최근 기록, 수업 메모를 관리합니다. 지난달에서 이어진 진도도 표시됩니다.
- **실제 남은 수업 횟수 확인**: 시간표와 학사일정, 수업 조정을 반영해 반별 남은 수업 횟수를 계산하고 남은 진도 차시와 비교해 적정, 여유, 부족으로 보여줍니다.
- **일정 관리**: 회의, 연수 등 일정을 등록하고 다가오는 일정을 확인합니다.
- **업무 및 마감일 관리**: 업무를 마감일과 중요도와 함께 관리하고, 마감이 지난 업무와 오늘 마감 업무를 확인합니다.
- **문서 업로드 및 분석**: 문서를 올리면 AI가 일정과 업무 후보를 추출하고, 사용자가 확인한 항목만 저장합니다.
- **Google Calendar 연동**: 선택 기능으로, 계정 권한을 승인하면 일정을 Google Calendar에 연결해 저장할 수 있습니다.

## 심사용 안내

- 심사 시에는 미리보기 모드 사용을 권장합니다.
- 미리보기에는 기능 확인을 위한 예시 시간표, 수업 진도, 일정, 업무 등의 데이터가 준비되어 있습니다.
- Google Calendar 연동은 실제 Google 계정의 권한 승인이 필요한 선택 기능이므로, 심사를 위해 별도로 연결하지 않아도 됩니다.
- 자세한 사용 방법은 별도로 제출하는 "사용 방법 또는 심사용 안내" PDF에서 확인할 수 있습니다.

## 참고

- 본 프로젝트는 Vite 기반 웹 애플리케이션입니다.
- dist 폴더는 배포용 빌드 결과물입니다.
- 실제 사용자 데이터와 미리보기 데이터는 분리하여 관리합니다.
